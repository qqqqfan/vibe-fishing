# 播放 / 暂停快捷键

1. 在小窗点击“快捷键设置”，进入详情的设置页。
2. 在“快捷键”区域点击当前快捷键（默认 Fn）。
3. 按 Fn，或包含 ⌘、⌃、⌥ 至少一个修饰键的组合键，例如 ⌃⌥Space。
4. 有效快捷键会自动保存；关闭并重新打开应用仍保留。

录入时：Esc 取消；Delete 清除；“恢复 Fn”恢复默认。

连接后按一次，根据当前检测到的视频状态切换播放 / 暂停。未连接、播放状态未知、正在切换或镜像被用户接管时，不保证执行切换。

录入期间暂停快捷键执行，避免录入本身误触视频。纯字母或只有 Shift 的组合不会保存，避免日常打字触发。

快捷键监听不独占系统事件：请避开系统和 AI 应用的已有快捷键。Fn 可能同时触发系统键盘设置里的功能。当前不自动检测快捷键冲突。
